First public release of **Unify3D Agent**, an AI design agent for SOLIDWORKS.

- Chat with the agent in the SOLIDWORKS Task Pane; it reads and changes your model through the SOLIDWORKS API.
- Conversations are saved inside your part, assembly and drawing files.
- Select faces and edges or draw on the view to show the agent what you mean.
- Save your own reusable tools; each gets a button and icon on the **Unify3D Tools** ribbon tab.
- Design Library support for reusing standard parts.
- Automatic updates (Options > Updates).

Requires Windows 10/11 x64, SOLIDWORKS 2024 or newer, and an Anthropic API key.
