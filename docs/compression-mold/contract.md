## Scope decisions for v1 (from critique; apply them)
1. v1 BUILDS flash-type molds for process classes A (liquid pour) and B (compression, flash/overflow + stop pads). Class C (positive: PEEK, PTFE, UHMWPE) and class B parts deeper than wide (semi-positive) get an advisory plan + "not built by this tool in v1" (A10, G2). Keep their material rows (advisory).
2. Bolts: tightening scatter + hot proof factor (A1). Joints/keys/bolts also checked at LC1x abuse with SF 1.0 / n0 >= 1.0, or the max gauge is capped (A3).
3. Lifting: lid default from the NIOSH lifting equation with 3 remembered answers (lift location table/press, reach, lifts/hour); fallback 11 kg (25 lb); plate default 23 kg for occasional lifts; lifting index on the setup sheet (A2).
4. Walls: tabulate L/h 6, 8, 12 and use the strip-with-shear closed form above (A4); monotonic test.
5. Shrink: `shrink_basis` choice (datasheet steel mold / measured in my molds at this temperature / hot cavity to cold part) + a one-time "v1 style 1+S" option; retag hot-cast PU rows or flag basis uncertain (A5).
6. Scale about a `MOLD CS` coordinate system at the parting-plane centroid (swScaleAboutCoordinateSystem = 2), fallback documented (A6). Acceptance: PL planes lie on the scaled silhouette within 0.01 mm.
7. Parting-line candidates classified per tessellation sample; 0-draft samples may go either side (A7). Fixtures: 0 deg puck, sphere, O-ring.
8. Temperature gates stress-aware; refuse T > 250 C (no data); D_b = 4 above 150 C for aluminium bearing until creep data (A8).
9. Force projected area includes overflow grooves and loading wells; p_LC1 uses the smaller area (A9).
10. Gap budget: delta_allow = delta_flash - flatness tolerance; walls in flash molds use 0.25 * t_tol on width; values in sizing-defaults (A11). Shut-off pins/faces 0.01-0.03 mm below the land + axial/Euler check (A12).
11. ToolRegistry: JToken schema guard + depth limit + a test that builds every [AgentTool] input schema (B1) - BEFORE any tool takes a JObject.
12. Checkpoints for molds keyed by the record GUID, stamped yyyyMMdd-HHmmss, restore by exact name or newest time, separate "mold design" registration flag (not a working copy of itself), keep last N (B2).
13. Stage order: 4.5 alignment+fastening, 4.6 stops, 4.7 handling (pry slots, lift, jack screws, TC wells, knockouts), 4.8 flash system, 4.9 finish (B3).
14. Rays: column casting with TOPOLS|NORMALS|ENTRY_EXIT|UNBLOCK, spacing max(sample_mm, sqrt(area/20000)) (B4).
15. Hook H1 runs after stage 4.1 (shrunk part exists) (B5).
16. One `HiddenDocuments.Scope()` sharing SwModelLoader's gate for every hidden open (B6).
17. Insert pockets get corner reliefs (dog-bone or R >= 1.1 x cutter radius) (B7). Import validated: one solid, no surfaces, Check3 clean, volume within 0.5% of the source (B8).
18. Page: per-field press unit choices (pressure psi/bar/MPa/kgf/cm2; force US ton/t/kN) remembered with the press; gauge Max 100 MPa, on-part Max 150 MPa (C1); always show the press rating; meaning option "Force reading (tons)" (C2); editable `molding_pressure` and `charge_excess_pct` in a collapsed "Process data" group with all filled fields (C3); `short` labels for families and grades (C5); inputs `stroke` (optional), `mold_handling` (slide in/out each cycle | stays in press), `mold_support` (flat on platen | carrier/rails) (C6).
19. Slide-in: lid-base dT default 30 K; dowels: one round + the others slotted radially (ask/confirm against the shop's 4-dowel practice) (D1). Handles outside the platen outline or below the lid's platen face; 25 mm margin applies to plates/cavities only; acceptance A16 (D2). Pour time = m/mdot + handling per cavity (mdot default 10 g/s) (D3).
20. Deliverables add: per-body machining sheet (hole table, fits with limits, flatness/parallelism, finish, stock) and a purchased-hardware BOM (stock bolt lengths, inserts + STI taps, dowels, washers; counterbores sized for washers) (E1, E2); partial-cavity loading table (E3); slide-in hardware (locating stop, base pull handles, nothing proud underneath) (E4); Phase 1a: drawing-only start builds the part from the drawing in its own SLDPRT, user confirms key dims (E5 - the user explicitly asked for this); cure note per class (E6).
21. Simulator hooks: findings located by {bodyId, point, normal, stepFaceId?}; reserve materials.part.rheology/kinetics/thermal/mechanical (status unknown); pressure samples (u,v,w,p) or per-face samples (F1-F3). No MCP client in v1 (record not_run).
22. Validation (G1): automated 3D linear-elastic solid check (~20 cases: wall-root factor, plates at tau >= 0.3) in the sweep console, plus bolt validation against VDI 2230-style worked examples; plate case B-F tables kept but case A is the default.
23. Overlay face items capped (~3000 triangles), outlines only while the camera moves (G3).
24. Sticky long-run settings only while mold.json status != done AND the active document is the mold; end at Phase 6 or after 2 h idle; shown in the banner (G4).
25. H-list fixes: E3 fails by 0.4% (S23 -> 8.66 mm); E11 expected values derived by hand; A10 pitch check as implemented; S56 labelled conservative; Shigley effective grip for tapped holes.
